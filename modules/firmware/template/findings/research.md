# Firmware Public Research Index

This is a compact index, not a second research report. Each question has exactly one canonical detail file under `reports/research/RQ-XX-....md`.

| ID | Narrow question | Local-first status | Research status | Effect on finding | Canonical detail |
|---|---|---|---|---|---|

`Local-first status` must say what was established in this firmware before browsing, including component/version/startup/use or useful negative evidence. Do not write bare questions such as `is component X vulnerable?` without target applicability.

Allowed research states:
- `OPEN`
- `ANSWERED`
- `PARTIAL`
- `NOT_FOUND`
- `SOURCE_LEAD_ONLY`
- `NEEDS_LOCAL_CONTEXT`

Do not duplicate source tables, credentials, hashes, private keys, private URLs, proprietary code, target-specific secrets or certificate fingerprints here.
